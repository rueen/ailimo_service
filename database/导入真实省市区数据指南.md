# 导入真实省市区数据指南

## 重要说明
本系统提供了真实的全国省市区数据导入方案，数据来源于开源项目 [modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)，包含：
- **34 个省级行政区**
- **300+ 个地级市**
- **2800+ 个区县**

## 方案一：自动下载并导入（推荐）

### 步骤 1：安装依赖
```bash
npm install axios --save
```

### 步骤 2：运行导入脚本
```bash
node scripts/import-regions.js
```

**说明**：
- 脚本会自动从 GitHub 下载最新数据
- 自动清空旧数据并导入新数据
- 显示实时进度
- 导入完成后显示统计信息

**优点**：
- ✅ 一键操作，简单快捷
- ✅ 自动获取最新数据
- ✅ 无需手动下载文件

**缺点**：
- ❌ 需要网络连接
- ❌ 依赖 GitHub 访问速度

---

## 方案二：从本地文件导入

如果网络环境不好或无法访问 GitHub，可以使用本地文件方式。

### 步骤 1：下载数据文件

访问 GitHub 仓库：https://github.com/modood/Administrative-divisions-of-China

下载以下三个文件到 `database/regions/` 目录：
- `dist/provinces.json` → `database/regions/provinces.json`
- `dist/cities.json` → `database/regions/cities.json`
- `dist/areas.json` → `database/regions/areas.json`

或者使用命令行下载（如果有 wget 或 curl）：

```bash
# 创建目录
mkdir -p database/regions

# 下载文件
cd database/regions

# 使用 wget
wget https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/provinces.json
wget https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/cities.json
wget https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/areas.json

# 或使用 curl
curl -O https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/provinces.json
curl -O https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/cities.json
curl -O https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/areas.json

cd ../..
```

### 步骤 2：运行导入脚本
```bash
node scripts/import-regions-local.js
```

**优点**：
- ✅ 不依赖实时网络
- ✅ 可以使用离线数据包
- ✅ 导入速度更快

## 验证导入结果

导入完成后，可以通过以下方式验证：

### 1. 查看数据库
```sql
-- 查询总数
SELECT level, COUNT(*) as count FROM regions GROUP BY level;

-- 查询省份
SELECT * FROM regions WHERE level = 1 LIMIT 10;

-- 查询某省的市（以广东省为例，code=440000）
SELECT * FROM regions WHERE parent_id = 440000 AND level = 2;

-- 查询某市的区（以深圳市为例，parent_id=440300）
SELECT * FROM regions WHERE parent_id = 44030000 AND level = 3;
```

## 数据更新

地区数据通常每年更新 1-2 次，当需要更新时：

1. 重新运行导入脚本（会自动清空旧数据）
2. 或者手动清空后重新导入：
   ```bash
   # 清空数据
   mysql -u root -p ailimo -e "TRUNCATE TABLE regions;"
   
   # 重新导入
   node scripts/import-regions.js
   ```

## 常见问题

### Q1: 导入过程中出现错误怎么办？
**A**: 检查以下几点：
- 数据库连接是否正常
- regions 表是否已创建（重启服务让 Sequelize 自动创建）
- 是否有足够的磁盘空间

### Q2: 导入需要多长时间？
**A**: 
- 方案一（自动下载）：5-10 分钟（取决于网络速度）
- 方案二（本地文件）：2-3 分钟

### Q3: 数据来源可靠吗？
**A**: 
- 数据来源于 GitHub 开源项目，有 15000+ stars
- 数据基于国家统计局官方行政区划
- 被大量项目使用，数据质量有保障

### Q4: 如何只导入部分省份的数据？
**A**: 可以修改导入脚本，在导入时添加过滤条件。例如：
```javascript
// 只导入广东省的数据
const provinces = allProvinces.filter(p => p.name === '广东省');
```

### Q5: 脚本执行失败，提示 axios 未安装？
**A**: 运行以下命令安装依赖：
```bash
npm install axios --save
```

如果安装失败，请使用方案二（本地文件方式）。

## 技术说明

### 数据结构映射
开源数据到本系统的字段映射：

| 开源字段 | 本系统字段 | 说明 |
|---------|-----------|------|
| code | code | 行政区划代码 |
| name | name | 地区名称 |
| - | id | 根据 code 计算得出 |
| - | parent_id | 根据 code 计算得出 |
| - | level | 1=省，2=市，3=区 |
| - | sort_order | 按导入顺序 |
| - | status | 默认 1（启用） |

### ID 生成规则
- **省级 ID**：`parseInt(code.substring(0, 2)) * 10000`
  - 例如：北京市 code=110000，ID=110000
- **市级 ID**：`parseInt(code.substring(0, 4)) * 100`
  - 例如：深圳市 code=440300，ID=44030000
- **区级 ID**：`parseInt(code)`
  - 例如：南山区 code=440305，ID=440305
