# 正式环境部署说明

## 数据库初始化完整流程

### 第一步：创建数据库

```sql
CREATE DATABASE ailimo CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 第二步：配置数据库连接

编辑 `config/index.js`，配置正式环境的数据库信息：

```javascript
db: {
  host: '生产数据库地址',
  port: 3306,
  database: 'ailimo',
  username: '数据库用户名',
  password: '数据库密码'
}
```

### 第三步：安装依赖

```bash
npm install --production
# 如果需要导入省市区数据，还需要安装 axios
npm install axios --save
```

### 第四步：初始化基础数据

```bash
# 1. 启动服务一次，让 Sequelize 自动创建所有表
npm start
# 等待服务启动成功后，按 Ctrl+C 停止

# 或者使用数据库同步脚本（如果有）
node database/sync.js
```

### 第五步：导入初始数据

#### 5.1 导入基础配置数据
```bash
mysql -u root -p ailimo < database/init.sql
```

这会导入：
- 默认管理员账号
- 系统配置
- 公司信息等基础数据

#### 5.2 导入省市区数据（重要）

**方案一：自动下载（推荐，如果服务器可以访问 GitHub）**
```bash
node scripts/import-regions.js
```

**方案二：从本地文件导入**
```bash
# 先将数据文件上传到 database/regions/ 目录
# provinces.json, cities.json, areas.json
node scripts/import-regions-local.js
```

**说明**：
- 脚本会自动创建 regions 表（如果不存在）
- 自动清空旧数据并导入新数据
- 导入约 3218 条省市区数据
- 耗时约 5-10 分钟

### 第六步：生成权限数据

```bash
node scripts/generate-permissions.js
```

这会自动：
- 扫描所有路由
- 生成权限数据
- 创建权限层级结构

### 第七步：启动服务

```bash
# 开发环境
npm run dev

# 生产环境（使用 PM2）
pm2 start ecosystem.config.js
```

## 快速部署脚本

为了简化部署流程，可以创建一个自动化部署脚本：

```bash
#!/bin/bash
# deploy.sh - 正式环境部署脚本

echo "=========================================="
echo "开始部署 ailimo_service"
echo "=========================================="

# 1. 安装依赖
echo "1. 安装依赖..."
npm install --production
npm install axios --save

# 2. 同步数据库表结构
echo "2. 同步数据库表结构..."
node database/sync.js

# 3. 导入基础数据
echo "3. 导入基础数据..."
mysql -u root -p ailimo < database/init.sql

# 4. 导入省市区数据
echo "4. 导入省市区数据（这可能需要几分钟）..."
node scripts/import-regions.js

# 5. 生成权限数据
echo "5. 生成权限数据..."
node scripts/generate-permissions.js

echo "=========================================="
echo "部署完成！"
echo "=========================================="
echo ""
echo "下一步："
echo "  - 启动服务: npm start 或 pm2 start ecosystem.config.js"
echo "  - 访问: http://your-server:3000"
echo "  - 默认管理员: admin / 123456"
echo ""
```

## 数据更新维护

### 更新省市区数据

当需要更新省市区数据时（通常每年1-2次）：

```bash
# 重新运行导入脚本，会自动清空并导入最新数据
node scripts/import-regions.js
```

### 更新权限数据

当添加新接口或修改权限结构后：

```bash
node scripts/generate-permissions.js
```

### 备份数据

```bash
# 备份整个数据库
mysqldump -u root -p ailimo > backup_$(date +%Y%m%d).sql

# 只备份数据（不含表结构）
mysqldump -u root -p --no-create-info ailimo > data_backup_$(date +%Y%m%d).sql

# 只备份省市区数据
mysqldump -u root -p ailimo regions > regions_backup_$(date +%Y%m%d).sql
```

## 环境变量配置（可选）

为了提高安全性，建议使用环境变量存储敏感信息：

```bash
# .env 文件
NODE_ENV=production
DB_HOST=数据库地址
DB_PORT=3306
DB_NAME=ailimo
DB_USER=用户名
DB_PASS=密码
JWT_SECRET=你的JWT密钥
OSS_ACCESS_KEY_ID=OSS密钥ID
OSS_ACCESS_KEY_SECRET=OSS密钥
```

修改 `config/index.js` 支持环境变量：

```javascript
require('dotenv').config();

module.exports = {
  db: {
    host: process.env.DB_HOST || 'localhost',
    port: process.env.DB_PORT || 3306,
    database: process.env.DB_NAME || 'ailimo',
    username: process.env.DB_USER || 'root',
    password: process.env.DB_PASS || ''
  },
  // ...其他配置
};
```

## 注意事项

1. **首次部署必须按顺序执行**，特别是：
   - 先创建表（sync）
   - 再导入基础数据（init.sql）
   - 最后导入省市区和权限数据

2. **省市区数据必须导入**，否则用户注册和订单提交时无法选择地区

3. **生产环境建议**：
   - 使用 PM2 管理 Node.js 进程
   - 配置 Nginx 反向代理
   - 启用 HTTPS
   - 设置防火墙规则
   - 定期备份数据库

4. **安全检查**：
   - 修改默认管理员密码
   - 修改 JWT 密钥
   - 检查文件上传权限
   - 配置 CORS 白名单

## 常见问题

### Q: 导入省市区数据失败怎么办？

**A**: 检查以下几点：
1. 确保 regions 表已创建（脚本会自动创建）
2. 检查网络连接（方案一需要访问 GitHub）
3. 如果网络不好，使用方案二（本地文件导入）

### Q: 如何验证部署是否成功？

**A**: 按顺序检查：
1. 数据库是否有所有表（约 20+ 张表）
2. regions 表是否有数据（约 3218 条）
3. permissions 表是否有数据（约 100+ 条）
4. 能否正常登录管理后台
5. 能否正常查询省市区接口

### Q: 生产环境如何回滚？

**A**: 
1. 停止服务
2. 恢复代码到上一个版本
3. 恢复数据库备份（如果有数据变更）
4. 重启服务
