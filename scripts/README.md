# 权限批量生成脚本使用说明

## 功能说明

`generate-permissions.js` 脚本可以自动从路由文件中提取权限信息，并批量生成权限数据到数据库中。

## 使用方法

### 方式一：使用 npm 脚本（推荐）

```bash
npm run generate-permissions
```

### 方式二：直接运行脚本

```bash
node scripts/generate-permissions.js
```

## 工作原理

1. **解析路由文件**：自动读取 `routes/admin.js` 文件，提取所有使用 `permission()` 中间件的路由
2. **构建权限树**：根据预定义的权限分组配置，构建三级权限树结构：
   - 一级权限：模块（如：系统管理、用户管理、设备预约等）
   - 二级权限：子模块（如：管理员管理、角色管理、设备管理等）
   - 三级权限：具体操作（如：列表、创建、更新、删除等）
3. **批量插入**：按层级顺序插入数据库，确保父子关系正确

## 权限分组配置

脚本会根据以下模块分组自动生成权限：

- **系统管理**：管理员、角色、权限、系统配置
- **用户管理**：用户、组织机构、课题组
- **设备预约**：设备、设备订单、设备时间段
- **笼位预约**：笼位、笼位订单、笼位用途、笼位时间段
- **实验代操作**：实验订单、操作内容、实验时间段
- **动物订购**：动物订单、品牌、品系、规格、需求
- **试剂耗材**：试剂订单、品牌、规格
- **内容管理**：案例、公司信息、负责人、环境类型、动物类型

## 注意事项

1. **已存在权限处理**：脚本使用 `findOrCreate` 方法，如果权限已存在则跳过，不会重复创建
2. **事务保护**：所有操作在事务中执行，如果出错会自动回滚
3. **权限代码格式**：权限代码格式为 `模块:操作`，如 `user:list`、`equipment:create`
4. **跳过权限管理权限**：为避免循环依赖，脚本会自动跳过 `permission:*` 相关的权限

## 输出示例

运行脚本后，会输出类似以下信息：

```
开始生成权限数据...
从路由文件中提取到 85 个权限
权限统计：一级权限 8 个，二级权限 25 个，三级权限 85 个
创建一级权限: 系统管理 (system)
创建二级权限: 管理员管理 (administrator)
创建三级权限: 管理员管理列表 (administrator:list)
...
✅ 权限生成完成！
当前数据库中共有 118 个权限
```

## 自定义配置

如果需要修改权限分组，可以编辑 `scripts/generate-permissions.js` 文件中的 `PERMISSION_GROUPS` 配置对象。

## 故障排除

1. **数据库连接失败**：确保数据库配置正确，且数据库服务正在运行
2. **路由文件解析失败**：检查 `routes/admin.js` 文件是否存在且格式正确
3. **权限代码格式错误**：确保路由中的权限代码格式为 `模块:操作`
