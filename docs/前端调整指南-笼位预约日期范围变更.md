# 前端调整指南 - 笼位预约日期范围变更

## 📋 变更概述

**变更日期：** 2026年1月

**影响范围：** 笼位预约模块

**变更类型：** 重大功能调整

### 变更说明

笼位预约功能从**单日+时间段选择模式**调整为**日期范围预约模式**，不再需要选择具体时间段。

**旧模式：**
- 选择单个日期：2026-01-22
- 选择多个时间段：09:00-10:00, 10:00-11:00, 11:00-12:00

**新模式：**
- 选择开始日期：2026-01-22
- 选择结束日期：2026-02-22（可选，不填表示长期预约）

### 2. 新增的接口

#### 2.1 查询笼位剩余可用数量

**H5端接口地址：** `GET /api/h5/cages/available-quantity`

**管理端接口地址：** `GET /api/support/cages/available-quantity`

**接口说明：** 查询指定动物类型、环境类型在指定日期范围内的笼位剩余可用数量（返回日期范围内每天的最小可用数量）

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `animal_type_id` | Number | 是 | 动物类型ID |
| `environment_id` | Number | 是 | 环境ID |
| `start_date` | String | 是 | 开始日期，格式：YYYY-MM-DD |
| `end_date` | String | 否 | 结束日期，格式：YYYY-MM-DD，不传或传null表示查询长期预约的可用性 |

**请求示例：**

```javascript
// 查询指定日期范围
GET /api/h5/cages/available-quantity?animal_type_id=1&environment_id=2&start_date=2026-01-22&end_date=2026-02-22

// 查询长期预约可用性（只传开始日期）
GET /api/h5/cages/available-quantity?animal_type_id=1&environment_id=2&start_date=2026-01-22
```

**返回数据：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total_quantity": 50,
    "available_quantity": 15
  }
}
```

**返回字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `total_quantity` | Number | 该动物类型+环境的笼位总数量 |
| `available_quantity` | Number | 日期范围内的最小可用数量（日期范围内每天可用数量的最小值）|

**业务逻辑说明：**

1. 查询符合条件（动物类型+环境）的笼位总数量
2. 遍历日期范围内的每一天
3. 计算每天的已预约数量（考虑所有覆盖该日期的预约订单）
4. 计算每天的剩余可用数量 = 总数量 - 已预约数量
5. 返回所有天中的**最小剩余可用数量**

**为什么返回最小值？**
- 确保用户预约的数量在整个日期范围内都有足够的笼位
- 避免出现某些日期可用但其他日期不可用的情况

## ⚠️ 注意事项

### 1. 日期范围验证

**前端需要增加的验证：**

- ✅ 开始日期不能早于今天
- ✅ 结束日期不能早于开始日期
- ✅ 如果是长期预约，end_date 必须传 null（不是空字符串）
- ✅ 预约数量不能超过可用数量
- ✅ 开始日期和结束日期可以相同（表示单日预约）

### 2. 长期预约处理

```javascript
// ❌ 错误写法
const data = {
  start_date: '2026-01-22',
  end_date: '' // 空字符串是错误的
}

// ✅ 正确写法
const data = {
  start_date: '2026-01-22',
  end_date: null // 必须是 null
}
```

### 3. 可用数量查询时机

**建议在以下情况查询可用数量：**

1. 用户选择完动物类型和环境类型后
2. 用户选择或修改开始日期后
3. 用户选择或修改结束日期后
4. 用户切换"长期预约"选项后

**使用防抖优化：**

```javascript
import { debounce } from 'lodash-es'

// 防抖查询（避免频繁请求）
const fetchAvailableQuantity = debounce(async () => {
  // 查询逻辑...

```

### 4. 列表筛选调整

### 5. 订单详情展示

**显示预约期限：**

```javascript
// 计算预约天数的辅助函数
function getReservationPeriod(startDate, endDate) {
  if (!endDate) {
    return '长期预约'
  }
  
  if (startDate === endDate) {
    return '单日预约'
  }
  
  const start = new Date(startDate)
  const end = new Date(endDate)
  const days = Math.ceil((end - start) / (1000 * 60 * 60 * 24)) + 1
  
  return `${days}天`
}

// 使用示例
const period = getReservationPeriod('2026-01-22', '2026-02-22')
// 返回: "32天"
```
