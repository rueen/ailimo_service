## 🚀 短信服务使用说明

### 1. 验证码配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 验证码长度 | 6 位 | 数字验证码 |
| 有效期 | 5 分钟 | 超时后验证码失效 |
| 每日限制 | 10 次/手机号 | 防止滥用 |

### 2. 短信模板参数

您的短信模板 `SMS_330451071` 应该包含以下变量：
- `${code}`: 验证码

**示例模板内容**：
```
您的验证码是${code}，5分钟内有效，请勿泄露。
```

### 3. API 接口测试

#### H5 端发送验证码接口

**接口地址**: `POST /api/h5/auth/send-code`

**请求参数**:
```json
{
  "phone": "13800138000",
  "type": "register"
}
```

**type 可选值**:
- `register`: 注册
- `login`: 登录
- `reset_password`: 重置密码
- `bind_phone`: 绑定手机号

**响应示例**:
```json
{
  "code": 200,
  "message": "验证码已发送",
  "data": null
}
```

### 2. utils/sms.js

**新增导入**:
```javascript
const Dysmsapi20170525 = require('@alicloud/dysmsapi20170525');
```

**实现真实发送**:
```javascript
// 创建客户端
const client = new Dysmsapi20170525({
  accessKeyId: config.sms.accessKeyId,
  accessKeySecret: config.sms.accessKeySecret,
  endpoint: 'dysmsapi.aliyuncs.com'
});

// 发送短信请求参数
const sendSmsRequest = new Dysmsapi20170525.SendSmsRequest({
  phoneNumbers: phone,
  signName: config.sms.signName,
  templateCode: config.sms.templateCode,
  templateParam: JSON.stringify({ code })
});

// 发送短信
const result = await client.sendSms(sendSmsRequest);
```

## 🔧 故障排查

### 问题 1: 短信发送失败

**可能原因**:
- 签名或模板未审核通过
- AccessKey 权限不足
- 账户余额不足
- 手机号格式错误

**解决方法**:
1. 检查阿里云控制台签名和模板状态
2. 查看日志文件中的具体错误信息
3. 确认账户余额充足

### 问题 2: 收不到短信

**可能原因**:
- 手机号在运营商黑名单中
- 短信发送频率过快
- 模板内容包含敏感词

**解决方法**:
1. 更换手机号测试
2. 遵守发送频率限制
3. 检查模板内容

### 问题 3: 验证码验证失败

**可能原因**:
- 验证码已过期
- 验证码已被使用
- 验证码输入错误

**解决方法**:
- 检查数据库 `sms_codes` 表中的记录
- 查看 `expire_time` 和 `is_used` 字段
