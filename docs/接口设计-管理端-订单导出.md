# 管理端 - 订单导出接口

基础路径：`/api/support`

认证方式：Bearer Token（管理端登录后获取）

---

## 1. 设备预约订单导出

**GET** `/equipment-reservations/export`

### 入参（Query）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| equipment_id | Number | 否 | 设备ID |
| equipment_name | String | 否 | 设备名称（模糊匹配） |
| user_id | Number | 否 | 用户ID |
| user_name | String | 否 | 用户姓名（模糊匹配） |
| user_phone | String | 否 | 用户手机号（模糊匹配） |
| status | Number | 否 | 订单状态：0-待审核 1-进行中 2-已拒绝 3-已完成 4-已取消 |
| order_sn | String | 否 | 订单号（精确匹配） |
| reservation_date | String | 否 | 预约日期（精确，格式：YYYY-MM-DD） |
| start_date | String | 否 | 开始日期（格式：YYYY-MM-DD） |
| end_date | String | 否 | 结束日期（格式：YYYY-MM-DD） |

## 公共说明

- 所有导出接口均**不分页**，返回符合查询条件的全部数据
- 查询入参与对应订单列表接口完全一致（无需传 `page` / `pageSize`）
- 订单状态值说明：`0`=待审核，`1`=进行中，`2`=已拒绝，`3`=已完成，`4`=已取消
- 来源（source）：`1`=用户提交，`2`=管理员代提交
