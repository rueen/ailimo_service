# 笼位房间相关变更说明（H5 端）

> 本文档仅描述**笼位房间**相关的接口与数据变动，供前端对接使用。具体实现由前端自行完成。

---

## 一、新增接口

### 根据动物类型和环境类型获取房间选项

| 项目 | 说明 |
|------|------|
| 方法 | GET |
| 路径 | `/api/h5/cages/rooms-by-animal-type-and-environment` |
| 查询参数 | `animal_type_id`（必填）：动物类型ID<br>`environment_id`（必填）：环境类型ID |
| 响应示例 | `data`: `[{ "id": 1, "name": "101房间" }, ...]` |
| 用途 | 笼位预约时，用户选择动物类型和环境类型后，获取可选房间列表 |
| 权限 | 无需登录 |

---

## 二、已有接口变动

### 2.1 查询笼位剩余可用数量 `GET /api/h5/cages/available-quantity`

- **请求变动**：增加参数 `room_id`（房间 ID）。

### 2.2 提交笼位预约订单 `POST /api/h5/cage-orders`

- **请求变动**：增加参数 `room_id`（房间 ID）。
- **响应变动**：返回数据中增加 `room_id`（可为 `null`）。

### 2.3 我的订单详情（笼位预约类型）

- 当订单类型为笼位预约（`type === "cage"`）时，详情接口返回中增加 **`room`** 对象（可为 `null`）。
  - `room`: `{ "id": 1, "name": "101房间" }`
- 用于在订单详情页展示预约的房间信息。
