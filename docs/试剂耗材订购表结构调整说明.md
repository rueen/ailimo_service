# 试剂耗材订购表结构调整说明

## 变更日期
2026-01-25

## 变更原因
简化试剂耗材订购流程,将品牌和规格从独立管理的表结构改为直接在订单中填写文本,提高系统灵活性和易用性。

## 数据库变更

### 1. 删除的表
- `reagent_brands` (试剂耗材品牌表) - ✓ 已删除
- `reagent_specifications` (试剂耗材规格表) - ✓ 已删除

### 2. 修改的表
**reagent_orders (试剂耗材订购订单表)**

#### 新增字段:
- `brand_name` VARCHAR(200) NOT NULL COMMENT '品牌名称'
- `specification_name` VARCHAR(200) NOT NULL COMMENT '规格名称'

#### 移除字段:
- `brand_id` INT UNSIGNED NOT NULL COMMENT '品牌ID'
- `specification_id` INT UNSIGNED NOT NULL COMMENT '规格ID'

#### 移除索引:
- `idx_brand` (brand_id 索引)

## 接口变更

### 管理端接口 (影响范围: `/api/support`)

#### 1. 试剂耗材订购订单管理

**1.1 订单列表接口** `GET /api/support/reagent-orders`
- 入参变更:
  - ❌ 移除: `brand_id` (品牌ID筛选)
  - ❌ 移除: `specification_id` (规格ID筛选)
  - ✅ 新增: `brand_name` (品牌名称模糊查询)
  - ✅ 新增: `specification_name` (规格名称模糊查询)
- 出参变更:
  - ❌ 移除: `brand` 对象 `{ id, name }`
  - ❌ 移除: `specification` 对象 `{ id, name }`
  - ✅ 新增: `brand_name` 字符串
  - ✅ 新增: `specification_name` 字符串

**1.2 订单详情接口** `GET /api/support/reagent-orders/:id`
- 出参变更:
  - ❌ 移除: `brand` 对象 `{ id, name }`

  - ✅ 新增: `specification_name` 字符串

**1.3 新增订单接口** `POST /api/support/reagent-orders`
- 入参变更:
  - ❌ 移除: `brand_id` (必填)

## 注意事项

1. **此迁移不可逆**: 一旦执行迁移,品牌和规格表的数据将永久删除
2. **无数据影响**: 已确认 reagent_orders、reagent_brands、reagent_specifications 表均无历史数据
3. **接口兼容性**: 前端需要同步更新,旧接口将不再可用
4. **字段长度**: brand_name 和 specification_name 字段最大长度为 200 字符
5. **必填字段**: 两个新字段都是 NOT NULL,创建订单时必须提供
